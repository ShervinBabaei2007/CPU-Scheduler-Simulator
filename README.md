# CPU Scheduler Simulator

A C++ console application that simulates CPU scheduling algorithms
and displays real Windows processes using the Windows ToolHelp API.

## Features

- Manual process input
- FCFS scheduling simulation
- Arrival-time sorting
- Finish time calculation
- Windows process enumeration

## Concepts Practiced

- C++ functions
- Arrays
- References
- Dynamic memory allocation
- Windows API
- CPU scheduling algorithms

## Future Improvements

- Add Round Robin scheduling
- Add Shortest Job First scheduling
- Replace arrays with std::vector
- Add process statistics
